# Customer Segmentation and Customer Behavior Analysis

## Project Overview
This project analyzes customer purchasing behavior using SQL, Orange Data Mining, and Power BI. It combines data analysis, machine learning, and visualization to explore customer characteristics and identify customer segments.

## Tools Used
- **MySQL Workbench:** Data cleaning and SQL analysis.
- **Orange Data Mining:** K-Means clustering and cluster evaluation.
- **Microsoft Power BI:** Dashboard creation and data visualization.

## Dataset
The dataset contains 3,900 customer records, including age, gender, product category, purchase amount, subscription status, payment method, and previous purchases.

## Project Workflow

### 1. SQL Analysis
- Explored the customer dataset.
- Checked for missing values and duplicate records.
- Analyzed customer purchasing patterns using SQL.

### 2. Customer Segmentation
- Selected relevant numerical features.
- Applied K-Means clustering in Orange Data Mining.
- Evaluated clustering performance using the Silhouette Score.
- Examined the characteristics of the resulting customer groups.

### 3. Power BI Dashboard
- Created visualizations to explore customer purchasing behavior.
- Analyzed purchase patterns across categories, age groups, and locations.
- Presented key metrics and insights in a dashboard.

## Conclusion
This project demonstrates practical experience in SQL, data preparation, unsupervised machine learning, customer segmentation, and Power BI dashboard development.

It illustrates how data analysis can help businesses understand customer behavior and support data-driven decisions.
